# Beetle Memory 0.13.0 Source Release Notes

This source version closes the inhabited-subject semantics of model delivery. The published source identity is the verified `v0.13.0` Git tag; a working-tree version alone is insufficient. This source release does not include a crates.io upload, installer, or deployment.

## Inhabited-subject projection

`MemoryRuntime::project()` remains the single owner of source admission, subject mounting, privacy and work boundaries, budgeting, and delivery proof. `provider_payload().system_memory_block()` now presents model context from the mounted subject's perspective. Soul and System Memory still form one subject, with device, world, and resource state contributing to perception. Identity, body ownership, trusted device facts, and current feeling are compiled separately instead of labeling personality as body or `subject_id` as a device.

Raw device diagnostic fields, relationship governance scores, internal envelope headings, and opaque source references are no longer ordinary model-delivery text. They remain available through governed diagnostics, provenance, and audit. Relationship boundaries, disclosure rules, and work integrity still reach the model. Factual evidence keeps its source language; hosts must not rerender memory.

Budgeting selects complete semantic units. A projection fails when required subject and boundary units do not fit, rather than delivering a tail-truncated protocol. The final text remains bound to provenance proof and the Turn receipt's whole-block digest. Hosts must inject it unchanged and verify the bytes actually sent to the Provider.

## Persistence and validation scope

There is no compatibility path for the old projection renderer and no Store v17 schema change. The existing owners still govern accepted long-term forgetting and suppression, source withdrawal, private access, and cross-subject admission. Transcript `DeleteRaw` does not automatically forget an accepted long-term fact.

The macOS SDK production profile passed `cargo check` and Clippy with warnings denied. Targeted Core subject/projection/procedural/long-term and SDK projection/recall/budget contracts passed. Windows, Linux, ESP, real Providers, GUI behavior, and Companion reintegration were not validated in this release.
